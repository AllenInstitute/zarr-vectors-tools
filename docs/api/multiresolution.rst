Multiresolution
===============

``zarr_vectors_tools.multiresolution``: build coarser levels. ``coarsen`` is
the entry point; ``strategies`` holds the per-geometry rules. ``zvtools
pyramid`` calls these; see :doc:`../pyramids`.
